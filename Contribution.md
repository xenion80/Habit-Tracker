# Contributing to Habit Tracker API

Thanks for your interest in contributing to this project.

This repository contains a backend REST API built with Spring Boot for tracking
habits, tasks, and categories. The project is intentionally kept simple and
focused, so please read the guidelines below before contributing.

---

## Project Scope

The goal of this project is to provide a clean, understandable backend service.

Contributions are welcome if they:
- fix bugs
- improve code quality or readability
- improve documentation
- improve developer experience

Please avoid large feature additions or architectural changes unless discussed
first via an issue.

---

## How to Contribute

### 1. Fork the repository
Fork the project on GitHub and clone your fork locally.

```bash
git clone https://github.com/xenion80/Habit-Tracker.git
cd Habit-Tracker
```

---
### 2. Create a new branch

Create a branch for your change.
```bash
git checkout -b feature/your-feature-name
```

### 3. Make your changes

While working on your changes, please ensure that:

- the project builds successfully
- existing functionality is not broken
- changes are focused and minimal
### 4. Commit your changes

Write clear and meaningful commit messages.

```bash
git commit -m "Describe your change clearly"
```
### 5. Push to the Branch
   ```bash
   git push origin feature/AmazingFeature
   ```
### 6. Open a Pull Request

Push your branch and open a pull request against the main branch.

In your pull request:

 - describe what you changed
 - explain why the change is needed
 - reference any related issues if applicable

### Code Style Guidelines

- Follow standard Java and Spring Boot conventions
- Prefer clarity over cleverness
- Keep controllers thin and business logic in services
- Avoid unnecessary abstractions
